# Utkarsh Organic Demo

Create a premium, modern, animated, fully responsive ecommerce website demo for a brand called “Utkarsh Organic”.

The company sells organic food ingredients and natural powdered products, with approximately 10 products. The primary product is Organic Onion Powder, along with similar dehydrated and organic food products.

The website should look like a real export-quality organic food brand, not a basic ecommerce template. The UI should feel natural, clean, trustworthy, premium, and modern.

Use React.js for the frontend. The website must be fully responsive for desktop, laptop, tablet, and mobile devices.

IMPORTANT DESIGN INSTRUCTION

Do not create a generic Shopify-style template.

The final design should feel like a combination of:

Premium Organic Brand + Modern D2C Ecommerce + Farm-to-Table Storytelling + Professional B2B Food Ingredient Supplier

Make the homepage visually immersive with premium organic imagery, tasteful animations, clean whitespace, strong product photography and polished micro-interactions.

The Organic Onion Powder should remain the hero/bestselling product while all 10 products receive their own professional ecommerce presentation.

The final website should be polished enough to use as a professional client demo for Utkarsh Organic.

```sh
npm i

```
